
**Мои настройки nvim c плагином NvChad**

*Установка:*


Рекомендуется выполнить команды, чтобы очистить старые конфигурации:

``` bash
rm -rf ~/.config/nvim
rm -rf ~/.local/state/nvim
rm -rf ~/.local/share/nvim
```
Склонировать конфигурацию.

```bash
git clone https://github.com/mr-shifty/my-nvim-on-NvChad.git ~/.config/nvim/ --depth 1
```

*Подробнее про установку, обновление и удаление:*

https://nvchad.com/docs/quickstart/install
